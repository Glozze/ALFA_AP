# ALFA_AP

Wifi Access Point for ALFA Network AWUS036AXML adapter. It is suitable for network attack practice.



------------------------
Follow the Steps:
------------------------
1. Download the alfa_ap.sh file.
2. Open linux terminal.
3. sudo su
4. vim alfa_ap.sh
5. chmod +x alfa_ap.sh //Give privileges to the script
6. sudo ./alfa_ap.sh
